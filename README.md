# بوردنق — تطبيق مصاريف السفر والقطّات

تطبيق ويب عربي (RTL) لتنظيم رحلات القروب على أساس **قطة القروب (صندوق مشترك)** + **ميزانية شخصية لكل فرد**، بعملتين (الوجهة + الديار)، مع **تجارب الأعضاء على الأماكن** وبحث خرائط قوقل. يعمل كموقع وكتطبيق جوال (PWA)، والبيانات تُحفظ محليًا في المتصفّح.

## الفكرة

1. **أمير الرحلة** ينشئ الرحلة، يضيف القروب (بالاسم ورقم الجوال)، ويحدّد **قطة الرحلة**: الإجمالي، على مين (الكل أو أشخاص معيّنين)، وإيش تشمل.
2. القطة **تتقسّم على المشاركين**؛ الأمير **يطلبها عبر واتساب** بضغطة، والنظام يوضّح **مين سدّد ومين لا**، ويصرف من الصندوق ويبيّن المتبقي.
3. كل فرد في **«مصاريفي»** يحدّد **ميزانيته الكاملة**؛ تنخصم منها القطة تلقائيًا، والباقي مصاريفه الشخصية.
4. **قطّات مشتركة** بين أي عدد (٢ فأكثر) خارج الصندوق، تُقسّم بالتساوي وتتسوّى بينهم عبر **برق** — مرتّبة تحت القطة.
5. **الأماكن + تجارب الأعضاء**: بحث حي عبر خرائط قوقل، وكل عضو يضيف مكانًا وتقييمه (نجوم) وتجربته، والباقي يستفيد.

## المميزات

- **عملتان** مع سعر صرف يدوي، وخيار إدخال أي مبلغ (القطة/الميزانية/المصروف) بأي عملة مع تحويل فوري.
- **بحث خرائط قوقل الحي** داخل التطبيق (Places Autocomplete) عند تفعيل مفتاح، مع تراجع لبحث خارجي بدونه.
- **تجارب وتقييمات** الأعضاء لكل مكان مع متوسط تقييم.
- **PWA** قابل للتثبيت ويعمل دون اتصال.

## تفعيل بحث خرائط قوقل

1. من [Google Cloud Console](https://console.cloud.google.com/) أنشئ مشروعًا وفعّل **Maps JavaScript API** و**Places API**.
2. أنشئ **API Key**، وقيّده بـ HTTP referrers (نطاق موقعك) لأمانه.
3. في التطبيق: ⚙️ إعدادات الرحلة ← الصق المفتاح في «مفتاح خرائط قوقل». يُحفظ على جهازك فقط.

> بدون مفتاح، يعمل البحث بفتح قوقل ماب خارجيًا. ملاحظة: خرائط قوقل لا تعمل داخل رابط المعاينة (سياسة أمان تمنع السكربتات الخارجية) — تعمل عند الاستضافة الحقيقية.

## النشر على GitHub Pages

يحتوي المستودع على `.github/workflows/pages.yml`. للتفعيل:

1. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
2. أي دفعة على الفرع تشغّل النشر تلقائيًا، ويطلع رابط الموقع في تبويب **Actions**.

## التشغيل محليًا

- **ملف واحد**: افتح `بوردنق-تطبيق-واحد.html` بالنقر المزدوج.
- **كموقع**: `python3 -m http.server 8080` ثم `http://localhost:8080`.

## البنية

```
index.html            الهيكل
css/styles.css        نظام التصميم
js/app.js             الواجهة + بحث خرائط قوقل + التجارب
js/store.js           البيانات + الحفظ المحلي
js/settle.js          حسابات القطة والميزانية والتسوية
js/icons.js           الأيقونات والفئات
manifest.json, sw.js  إعدادات PWA
.github/workflows/    نشر GitHub Pages
بوردنق-تطبيق-واحد.html  نسخة كل شيء في ملف واحد
```

## المزامنة السحابية (Supabase)

لمشاركة الرحلة مع القروب ومزامنتها لحظيًا بين الأجهزة:

1. أنشئ مشروع [Supabase](https://supabase.com) مجاني.
2. في **SQL Editor** نفّذ:
   ```sql
   create table if not exists public.trips (
     id text primary key,
     data jsonb not null,
     updated_at timestamptz not null default now()
   );
   alter table public.trips enable row level security;
   create policy "read"   on public.trips for select using (true);
   create policy "insert" on public.trips for insert with check (true);
   create policy "update" on public.trips for update using (true);
   alter publication supabase_realtime add table public.trips;
   ```
3. من **Project Settings → API** انسخ **Project URL** و**anon public key**.
4. في التطبيق: ⚙️ الإعدادات → الصق الرابط والمفتاح. ثم من زر المشاركة فعّل المزامنة لأي رحلة وشارك رابطها.

> المعرّفات عشوائية غير قابلة للتخمين. النموذج «آخر كتابة تفوز». المفتاح العام (anon) آمن للنشر مع تفعيل RLS.
