# بوردنق باس · BoardingPass

منصّة سفر للمجموعات: خطّط رحلتك، نسّق مجموعتك، وقسّم المصاريف — في مكان واحد.
تعمل على **كل الجوالات والأجهزة**، بلغتين (عربي/إنجليزي) مع اتجاه RTL كامل.

يحتوي المستودع على **جزأين**:

1. **النموذج الأولي الثابت** (جذر المستودع) — صفحات HTML/CSS/JS تُنشر على GitHub Pages.
2. **المنتج الفعلي** (`apps/`, `packages/`) — تطبيق React + TypeScript (وسقالة خلفية .NET وموبايل Expo)، مبني وفق **باك‌لوق ستوريز كامل** في `user-stories/`.

---

## 1) المنتج الفعلي — Monorepo (npm workspaces)

```
apps/
  web/        React 19 + TypeScript + Vite + React Router + Zustand + i18next   (مبني ومختبَر)
  api/        C# ASP.NET Core (.NET 10) — سقالة Clean Architecture + عقود Endpoints (غير مُترجم هنا)
  mobile/     React Native + Expo — سقالة (غير مبنية هنا)
packages/
  types/          أنواع مشتركة عبر المنصّات + Enums + عقود الأخطاء
  i18n/           حِزم الترجمة (عربي/إنجليزي) — مصدر واحد للويب والموبايل
  core/           ApiError + مصنع apiClient + أدوات التنسيق
  design-tokens/  متغيّرات CSS + ثوابت الألوان/المسافات
  validation/     مخططات Zod المشتركة
user-stories/     الباك‌لوق: نظرة عامة، أدوار وصلاحيات، معمارية، 16 ستوري + مصفوفات
```

### التشغيل والاختبار (الويب)

```bash
npm install                 # جذر المستودع (workspaces)
npm --workspace apps/web run dev        # تشغيل محلي
npm --workspace apps/web run typecheck  # فحص الأنواع
npm --workspace apps/web run test       # Vitest (129 اختبار)
npm --workspace apps/web run build      # حزمة الإنتاج
```

CI على `.github/workflows/ci.yml`: `npm ci → typecheck → test → build` (Node 22).

### أنماط الهندسة

- **خدمة قابلة للتبديل لكل ميزة**: `mock` للتطوير/الاختبار، وخدمة API خلف `VITE_API_BASE_URL`
  (تُستورد ديناميكيًا فتُستبعد من الحزمة عند عدم التهيئة).
- **منطق نقي مختبَر** لكل حساب حسّاس (تقسيم المصاريف، الأدوار، التحقق…): في وحدات `*.ts` بلا إطار.
- **متجر Zustand** لكل ميزة مع حقن الخدمة، ومكوّنات تقرأ من المتجر.
- **انضباط i18n**: لا نصوص مضمّنة؛ كل مفتاح موجود في `ar.json` و`en.json` (اختبار اكتمال يفرض ذلك).
- **أمان**: المفاتيح/الأسرار في الخادم فقط، والصلاحيات تُفرض خادميًا؛ فحوص الواجهة **UX فقط**.
- **تقسيم كود** للصفحات الثقيلة (لوحة الرحلة، الملف الشخصي، الرفقاء، الاستكشاف، الإدارة) عبر `React.lazy`.
