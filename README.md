# بوردنق · Boarding

موقع تنظيم رحلات المجموعات — تصميم من Google Stitch، مضبوط ليعمل على **كل الجوالات والأجهزة** (جوال، تابلت، لابتوب).

## الصفحات
| الصفحة | الملف | الوصف |
|--------|-------|-------|
| الرئيسية | `index.html` | الواجهة الأولى: إنشاء رحلة، المميزات، رحلاتك القادمة، تسجيل الدخول |
| الرحلة | `trip.html` | خط سير الرحلة: العد التنازلي، رحلات الطيران، المدن والسكن، الذكريات |
| التوصيات | `recommendations.html` | استكشاف الأماكن والمطاعم والأنشطة مع التقييمات |
| المصاريف | `expenses.html` | قطة الرحلة، حالة السداد، القطّات الجانبية، ملخّصك المالي |
| الأصدقاء | `friends.html` | إدارة الأصدقاء والمجموعات وطلبات الصداقة والدعوات |
| الملف الشخصي | `profile.html` | صفحة المستخدم |

## ضبط الاستجابة (Responsive)
- طبقة مشتركة: `assets/responsive.css` + `assets/responsive.js`.
- **شريط تنقّل سفلي** يظهر تلقائياً على الجوال (≤ 767px) لأن القائمة العلوية تختفي على الشاشات الصغيرة، ويبرز الصفحة الحالية.
- ربط روابط التنقل بين كل الصفحات تلقائياً.
- تصغير هوامش الترويسة/التذييل على الجوال، ومنع التمرير الأفقي، وإفساح مكان لشريط الجوال.
- الجداول العريضة (المصاريف) تُمرَّر أفقياً داخل حاويتها بدل كسر التخطيط.

## النشر
يُنشر تلقائياً على GitHub Pages عبر `.github/workflows/pages.yml` عند كل دفع للفرع.
