# بوردنق · Boarding

منصّة سفر للمجموعات مرتّبة حسب التسلسل الزمني لرحلة المسافر، تعمل على **كل الجوالات والأجهزة**.

## الهيكلة (Information Architecture)

القائمة العلوية = **4 أقسام** + زر «إنشاء رحلة» + الملف الشخصي. وعلى الجوال: درج جانبي + شريط سفلي من 5 أيقونات.

| القسم | الملف | المحتوى |
|-------|-------|---------|
| الرئيسية | `index.html` | الواجهة + مداخل الأقسام الأربعة |
| 🗓️ خطط لرحلتك | `planner.html` | لوحة تجمع أدوات ما قبل السفر |
| ↳ الجدول الزمني | `trip.html` | خط سير بالخريطة والأيام والطيران |
| ↳ المهام والحجوزات | `prep.html` | تشيك‑لست تفاعلي (طيران/سكن/فيزا/عملة/شريحة) |
| ↳ تجهيز الحقيبة | `packing.html` | قائمة تفاعلية + قوالب جاهزة بنقرة |
| ↳ حاسبة القطة | `expenses.html` | تقسيم المصاريف والتسوية |
| 🤝 خوّة سفر | `buddies.html` | رحلات كاملة + طلعات/تجمّعات + فلترة + إنشاء طلب |
| 🗺️ استكشف وتوصيات | `explore.html` | دليل الوجهات + اقتراحات |
| 📸 الذكريات والمجتمع | `memories.html` | ألبوم حسب الأيام/المكان + مشاركة تقرير |
| 🧳 رحلاتي والقروب | `mytrips.html` | إدارة الرحلة الحالية والقروب والدعوات |

## شريط الجوال السفلي (5)
🏠 الرئيسية · 🗺️ استكشف · ➕ رحلة جديدة (زر مركزي) · 🤝 خوّة سفر · 🧳 رحلاتي

## طبقة موحّدة (نظام تنقّل واحد)
- `assets/responsive.js` — يبني الترويسة والدرج والشريط السفلي على **كل** الصفحات، مع إبراز القسم الحالي وربط الروابط تلقائياً وزر الوضع الليلي.
- `assets/responsive.css` — تنسيق التنقّل + ضبط الاستجابة لكل المقاسات.
- `assets/theme.js` — هوية الألوان والخطوط الموحّدة (Tailwind).

## النشر
يُنشر تلقائياً على GitHub Pages عبر `.github/workflows/pages.yml` عند كل دفع للفرع.
