# رِفقة — تطبيق مصاريف السفر والقطّات

تطبيق ويب عربي (RTL) لتنظيم رحلات القروب: تحديد الوجهة، تعيين **أمير الرحلة** الذي يحدّد الأماكن، تسجيل **القطّات** وتقسيمها على المجموعة، ثم **التسوية والدفع** عبر برق — بأقل عدد تحويلات.

يعمل كموقع وكتطبيق على الجوال (PWA)، بدون سيرفر، والبيانات تُحفظ محليًا في المتصفّح.

## المميزات

- **إنشاء رحلة**: الوجهة + الدولة + العلم + العملة (ر.س افتراضيًا).
- **القروب وأمير الرحلة**: إضافة الأعضاء وتعيين أمير هو من يحدّد الأماكن.
- **مراحل الرحلة**: من شراء التذاكر ← الإقلاع والوصول ← تحديد الأماكن ← القطّات اليومية ← التسوية والدفع.
- **الأماكن**: يضيفها الأمير مع رابط قوقل ماب، أو بحث تلقائي في الخريطة باسم المكان، مع تعليم «تمّت الزيارة».
- **أنواع القطّات**:
  - **على القروب** — تنقسم على جميع الأعضاء.
  - **بين أشخاص** — تُقسّم على المشاركين المختارين فقط.
  - **خارج القطة** — مصروف شخصي (هدايا، تذاكر…) يخص صاحبه ولا يدخل التسوية.
- **التسوية الذكية**: حساب أرصدة الأفراد (له/عليه) وتحويلها إلى **أقل عدد تحويلات**، مع زر «ادفع عبر برق» لنسخ تفاصيل التحويل جاهزة.

## التشغيل محليًا

```bash
# من مجلد المشروع
python3 -m http.server 8080
# ثم افتح
http://localhost:8080
```

أو أي خادم ملفات ثابت. لا يحتاج بناء (No build) — HTML/CSS/JavaScript خام.

## النشر

المشروع ملفات ثابتة، يُنشر مباشرة على **GitHub Pages** أو أي استضافة ثابتة. لتثبيته كتطبيق: افتح الموقع في المتصفّح ← «إضافة إلى الشاشة الرئيسية».

## البنية

```
index.html          الهيكل
css/styles.css      نظام التصميم (سفري نظيف)
js/app.js           الواجهة والتنقّل والنوافذ
js/store.js         البيانات + الحفظ المحلي
js/settle.js        حساب الأرصدة والتسوية بأقل تحويلات
js/icons.js         أيقونات SVG وفئات المصاريف
manifest.json, sw.js  إعدادات PWA والعمل دون اتصال
icons/              أيقونات التطبيق
```

## ملاحظة على التصميم

تصميم بأسلوب سفر واقعي (بحر/رمل/حبر)، أيقونات خطّية بسيطة — بدون تدرّجات أو أيقونات ذات طابع «ذكاء اصطناعي».
