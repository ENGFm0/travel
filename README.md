# رِفقة — تطبيق مصاريف السفر والقطّات

تطبيق ويب عربي (RTL) لتنظيم رحلات القروب على أساس **قطة القروب (صندوق مشترك)** + **ميزانية شخصية لكل فرد**، بعملتين (الوجهة + الديار). يعمل كموقع وكتطبيق جوال (PWA) بدون سيرفر، والبيانات تُحفظ محليًا في المتصفّح.

## الفكرة

1. **أمير الرحلة** ينشئ الرحلة، يضيف القروب (بالاسم ورقم الجوال)، ويحدّد **قطة الرحلة**: الإجمالي، على مين (الكل أو أشخاص معيّنين)، وإيش تشمل.
2. القطة **تتقسّم على المشاركين** ويطلع نصيب كل فرد. الأمير يقدر **يطلبها عبر واتساب** بضغطة، والنظام يوضّح **مين سدّد ومين لا**.
3. القطة تُدفع للأمير، وهو **يصرف منها** على مصاريف القروب — ويبيّن المتبقي في الصندوق.
4. كل فرد في صفحة **«مصاريفي»** يحدّد **ميزانيته الكاملة**؛ تنخصم منها قطة الرحلة تلقائيًا، والباقي مصاريفه الشخصية التي تُخصم كل ما سجّل مشترى.
5. **قطة بين شخصين**: مصروف خارج الصندوق يخص شخصين، يُقسّم مناصفة ويتسوّى بينهما بأقل تحويل، مع الدفع عبر **برق**.

## المميزات

- **عملتان**: عملة الوجهة + عملة الديار مع سعر صرف يدوّنه الأمير — كل المبالغ تظهر بالعملتين، وتقدر تدخل أي مصروف بأي عملة.
- **حالة السداد**: مؤشّر لكل عضو (سدّد ✓ / بانتظار) ونسبة تحصيل القطة.
- **طلب عبر واتساب**: زر يفتح رسالة جاهزة بنصيب الفرد وطريقة الدفع (برق).
- **الأماكن**: يضيفها الأمير مع رابط قوقل ماب أو بحث تلقائي باسم المكان، مع تعليم «تمّت الزيارة».
- **PWA**: قابل للتثبيت على الجوال ويعمل دون اتصال.

## طرق التشغيل

- **ملف واحد بالنقر المزدوج**: افتح `رِفقة-تطبيق-واحد.html` مباشرة في المتصفّح — بدون أي إعداد.
- **كموقع كامل**: أي خادم ملفات ثابت، مثل:
  ```bash
  python3 -m http.server 8080   # ثم http://localhost:8080
  ```
- **نشر**: ملفات ثابتة تُنشر على GitHub Pages أو أي استضافة ثابتة.

```
js/store.js           البيانات + الحفظ المحلي
js/settle.js          حسابات القطة والميزانية والتسوية
js/icons.js           أيقونات SVG والفئات

icons/                أيقونات التطبيق
رِفقة-تطبيق-واحد.html   نسخة كل شيء في ملف واحد
```

## ملاحظات

- **البيانات محلية لكل جهاز** (بدون سيرفر). للمزامنة بين أجهزة القروب في الوقت الحقيقي نحتاج خلفية (مثل Firebase).
- التصميم بأسلوب سفري نظيف (بحر/رمل/حبر) بأيقونات خطّية بسيطة — بدون طابع «ذكاء اصطناعي».
